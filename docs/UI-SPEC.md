# 前端规格（web/）

目标：紧凑、键盘优先、暗色的 V2EX 阅读器。无构建步骤：原生 ES Modules + CSS，
不使用框架、不引入 CDN。所有请求走同源 `/api/*`。

## 文件结构（由前端实现）

```
web/
  index.html
  css/app.css
  js/app.js         入口、路由、状态机
  js/api.js         fetch 封装、错误处理
  js/vim.js         键盘/按键序列引擎
  js/render.js      列表/主题/楼层的 DOM 渲染
  js/lightbox.js    图片灯箱、视频点击加载
  js/overlays.js    帮助、命令面板、屏蔽菜单、提示条
  js/store.js       localStorage：已读、布局宽度、主题、过滤词
  js/mock.js        mock 模式数据（?mock=1 时使用，便于离线开发）
```

## 布局

- 顶部栏（约 38px）：站点名 `v2ex-vimreader`；主标签 `首页 / 最近 / 最新 / 按天`；
  右侧：同步状态点、限速提示、`?` 帮助。
- 左侧栏（可折叠，默认 220px）：常用节点、全部节点搜索入口、当前列表过滤框（`/`）。
- 主区域：列表视图或主题视图。
- 底部状态栏（约 22px）：当前上下文、页码、提示、快捷键提示、时间。
- 暗色为主题默认；CSS 变量支持浅色（`:root[data-theme=light]`）。

## 列表视图（紧凑单行）

每行 28-30px：
`[置顶] 标题 …………………………………………  节点  作者  回复数  最后回复时间`
- 标题过长省略号；数字/时间用等宽字体，弱化颜色。
- 当前行高亮（左边框 2px 强调色）。
- 已读主题标题变暗；屏蔽主题/用户的过滤在服务端和客户端各做一次。
- 页脚行显示：第 x/y 页，`j/k` 选择、`Enter` 打开、`]`/`[` 翻页、`r` 刷新。

## 主题视图

- 面包屑：节点 › 标题；右侧：作者、创建时间、回复数、`[未读/已读]`。
- 操作按钮/快捷键提示：刷新 `r`、AI 总结 `s`、屏蔽 `b`、复制链接 `y`。
- 楼主正文块，正文 HTML 直接渲染；图片最大高度 300px 圆角、点击打开灯箱；iframe 视频默认显示占位卡片（播放键 + 外链），点击后才加载 iframe。
- 楼层列表：每层上下留白 6-8px；首行 `#楼层 作者 时间 OP徽标`，正文紧凑呈现；
  楼主回复用左边框高亮；楼层间细分隔线。
- 快捷键：`j/k` 滚动/选中楼层，`]`/`[` 或 `n/p` 楼层翻页，`t` 跳到最新页，`gg` 顶部，`G` 底部，
  `q` 返回列表，`o/Enter` 打开图片/链接。
- 返回列表时记住列表滚动位置与选中行。

## Vim 快捷键总表（必须实现）

全局：`?` 帮助；`Esc` 关闭浮层/取消；`:` 命令面板；`g` 前缀序列。
列表：`j/k` 下/上，`gg/G` 首/尾，`Ctrl-d/u` 半页，`Ctrl-f/b` 整页，`Enter/l/o` 打开，
`h/q` 返回，`H/L` 历史后退/前进，`r` 刷新，`R` 强刷，`[/]` 上/下一页，
`1..9` 页码前缀，`/` 过滤，`n/N` 下一个/上一个匹配，`y` 复制链接，`b` 屏蔽菜单，
`x` 屏蔽当前主题，`u` 屏蔽当前主题作者，`m` 标记已读/未读，`s` AI 总结（主题视图）。
主题：`j/k` 滚动，`gg/G` 首/尾，`[/]` 楼层上一页/下一页，`t` 最新楼层页，`q` 返回，
`b/u/x` 屏蔽，`y` 复制链接，`i` 图片灯箱（当前楼层第一张图），`s` AI 总结。
命令面板（`:`）：`node <name>`、`day <YYYY-MM-DD>`、`home`、`recent`、`new`、
`refresh`、`theme dark|light`、`block-user <name>`、`block-topic <id>`、`unblock ...`、`sync`、`clear-cache`。

数字前缀：`5j` 移动 5 行，`3]` 翻 3 页。

## 视觉

- 暗色底：`#0e1116` / 面板 `#151a21` / 边框 `#232a34` / 文字 `#d6dde6` / 弱文字 `#7d8896`
  / 强调 `#4ea1ff` / 绿 `#3fb950` / 橙 `#d29922`。
- 字体：`-apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`；数字用 `ui-monospace, Consolas`。
- 紧凑但可读：正文 14px/1.6，列表 13.5px，楼层正文 14px。
- 焦点明确：活动行左侧 2px 强调条 + 背景微亮。
- 响应式：<900px 时侧栏变成抽屉（`\\` 或按钮切换）。

## 交互细节

- 所有网络请求显示细进度条/状态点；失败在状态栏显示可恢复错误，`r` 重试。
- 页面隐藏（`document.visibilityState`）时暂停前端轮询；不使用高频 `setInterval`。
- 键盘操作优先；鼠标可用（点击行打开、点击图片灯箱）。
- 图片灯箱：`Esc` 关闭，左右方向键切换同楼层图片，"打开原图"链接 `target=_blank rel=noopener`。
- 视频：识别 youtube/bilibili 链接与 iframe，显示卡片；点击后加载。
- 主题 HTML 已由后端消毒，前端不再做 HTML 过滤，但所有外链加 `target=_blank rel="noopener noreferrer"`。
- 列表滚动使用原生滚动，不做虚拟列表（每页 <= 25 行）；楼层每页 <= 100 层，直接渲染。
- 无障碍：焦点可见、按钮有 title、`aria-live` 状态栏。

## Mock 开发模式

`index.html?mock=1` 时 `api.js` 返回 `mock.js` 中的假数据（覆盖 bootstrap/list/topic/replies/blocks/summary），
这样前端可以在后端完成前独立开发和截图验收。假数据要覆盖：正常列表、空列表、需要登录的受限节点、
包含图片/iframe 的正文、AI 总结流式输出、屏蔽用户后过滤。

## 2026-10-26 重设计（已实现）

- 极简扁平：无卡片容器、无阴影/渐变/发光，圆角 ≤2px，全部 1px hairline；hover 只变底色。
- Token：底 `#0a0c0f`、面板 `#0f1216`、hover `#141920`、hairline `#232a33`、文字 `#c8d1da`、
  次要 `#78828c`、强调冷青 `#5bc8c8`；顶栏 36px、状态栏 20px、侧栏 200px、列表行 27px。
- 字体：正文/UI 系统无衬线；楼层号、作者、数字、时间、归档信息用 `ui-monospace, Consolas`。
- 楼层两列 grid：左栏 92px（<900px 时 64px）纵向放 `#楼层 → 作者(OP) → 时间`，时间默认透明，
  仅 `:hover` / 当前选中楼层显示；正文列占满剩余宽度，顶部对齐，行间 hairline。
- OP 正文全宽块 + 2px 强调左线；楼主回复左侧 2px 强调线；标题区/正文/回复三层用 hairline 与留白区分。
- 登录：状态栏 `#login-state`（未登录/已登录 user），`g l`、`:login` 打开浮层；POST/DELETE /api/login；
  Cookie 只存本地 SQLite，不返回给前端。

## 2026-10-26 晚间调整（已实现）

- 柔和边角：`--radius` 4px、`--radius-lg` 8px，按钮/输入框/浮层/badge/当前行统一圆角；滚动条 3px；
  分隔线颜色贴近背景，楼层用 9/10px 留白 + 1px 细线区分；仍然无阴影、无渐变。

  选中（OP 也作为一个可滚动选中项），`Ctrl-d/u/f/b` 直接滚视口且对 OP 有效。
- AI 总结：`.summary-panel` 为 `position: fixed` 右侧悬浮面板（宽 400px，topbar 下、statusbar 上，
  自身滚动；<900px 覆盖式抽屉），打开不改变阅读位置；含 loading、流式光标、缓存/已生成+模型、
  错误重试、复制、Esc/关闭；后端接口不变。
- 节点管理：侧栏「管理」按钮与 `:nodes` 打开；搜索自动聚焦、即时过滤全量节点；Space/Enter 切换、

- 登录快捷键：`L` 已改为 `g l`（列表/主题通用），原前进改为 `Ctrl-L`。

### 列表与节点管理器（2026-10-26 收尾）

- 列表行：`回复数(34px 固定列) | 标题 | 节点 | 作者 | 时间`。回复数在最左侧固定数字列（右对齐、mono、muted），
  所有行严格对齐；未知/0 回复显示 `-`；<900px 隐藏节点/作者、保留回复数。
- 节点管理器：打开默认聚焦 `.nm-list`（tabindex=0），j/k、↑↓ 直接生效；`/` 或点击进搜索框，搜索框
  Enter/Esc 返回列表；行 hover 只做视觉高亮，不再改选中（修复滚动时 mouseenter 抢焦点导致的跳行）；
  选中滚动用手动 `scrollTop` 保证选中行贴列表底/顶；已保存节点在打开时置顶，编辑时不重排，保存后按
  新列表重排并按 name 跟随当前项；底部提示为 `↓↑ / j k 移动`。
- 楼层滚动提前量：短楼层在视口 38%~62% 区间内不滚动，选中项越过该区间时页面才跟随；长楼层先滚完内容再切换。
  `Ctrl-d/u/f/b` 滚动半屏/整屏后，选中项落在视口中线附近。列表侧栏英文节点名固定 88px 列宽，中文标题从同一 x 开始。
- 键盘焦点不再用整行底色：`#focus-cursor` 为 3px 暖色短竖线，按当前楼层/主楼作者行定位，切换楼层时用 130ms 缓动平移（nvim 风格）；长主楼滚动时贴视口上沿；楼主回复只保留 OP 徽标、不加左侧强调线；楼层时间只在鼠标悬停时显示。
- 楼层阅读宽度：默认居中 1080px，按 `w` 或 `:wide` 切换为铺满主区域，偏好存 localStorage。
